🚀 React Practice Activities

This repository contains three interactive React practice exercises.

Available Practice Files:

  • practice1-press-button.html
    Create a clickable button that displays an alert when clicked.
    Topics: onClick events, event handlers
  • practice2-click-counter.html
    Build a click counter with conditional styling.
    Topics: useState hook, state management, conditional rendering
  • practice3-change-text.html
    Change text dynamically with multiple buttons.
    Topics: Multiple state updates, conditional CSS
  • react-practices-all.html
    All three practices in one convenient page.
    Combined demo of all exercises

How to Use:

  1. Open any HTML file directly in your browser (double-click the file)
  2. Interact with the components to see React in action
  3. Read the "Check Your Understanding" questions in each practice
  4. View the source code to learn React patterns

Note: These files use React, ReactDOM, and Babel from CDN. An internet connection is required for the first load.

💡 Learning Objectives:

  • ✓ Understand React component structure
  • ✓ Learn to use event handlers (onClick)
  • ✓ Master the useState hook for state management
  • ✓ Practice conditional rendering and styling
  • ✓ Build interactive user interfaces
